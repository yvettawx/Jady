## 1. 背景与目标

一个以本地为主、深度融合 AI 的综合内容系统，装下学习、创作、研究、工作和生活。它不是笔记软件，笔记只是其中一种内容。规模对标 Obsidian 或更大，按长期项目推进。

- **一个地方放下所有内容**，彼此可以链接。
- **记录轻松**，整理可以事后再做。
- **学得快、记得住**：AI 讲课、出题、批改，复习有规律，掌握程度看得见。
- **AI 深度融合**：AI 参与记录、整理、学习、创作和研究的每个环节；没网或额度用完时，基本功能仍然可用。
- **数据属于自己**：离线可用、加密同步、可以完整导出。
- **先自用，再开源**：先满足我自己每天用，打磨稳定后开源、免费推广给其他人。

## 2. 使用场景

第一个用户是我自己，下面的场景大多来自已经发生过的真实使用。之后开源推广，所以场景、默认内容和模板都要能适用于其他人，不写死我的个人信息。

- **S1 每天打开**：首页上看到热度图、掌握度、提醒，以及今天的日程和待办。
- **S2 随手记**：点新增，选一个类型，或者直接放进收集箱；没网也能记。
- **S3 快速学会一样东西**：AI 先摸底，再按资料讲课，每节出题检查；有截止时间时按时间倒排，结束后转成长期复习。（例：考前一天补数据库）
- **S4 边做边学**：写代码项目时记开发日志，学到的东西变成记忆卡，提交记录计入热度图；AI 和我一起把学到的写成自己的教材。（例：用 Rust 写 OS）
- **S5 写作训练**：贴上自己的文字，AI 把批评批注在原文上，我自己改，前后版本可以对比。（例：文学写作训练）
- **S6 研究与设定**：人物、地点、事件都是内容，配合时间轴和关系图；待定事项单独记。（例：架空历史小说设定）
- **S7 每周复盘**：到点提醒，由我发起；整理收集箱和没收尾的线头。
- **S8 求职**：AI 定期搜职缺写进库，我用表格筛选、用看板跟进投递；简历从个人档案生成。（例：M2 实习求职）
- **S9 生活**：每天打卡习惯，记下看完的书和电影，记账看月度开销，规划一次旅行的行程和预订。

**完整示例：法语实时对话**（以后设计其他学习零件时，可以参照这个流程）

1. 在“语言”领域下打开“法语”。法语的 AI 工作约定里写着我的水平和对话伙伴的设定，比如起步阶段用简单法语、配中文解释。
2. 新建，选择“实时对话”。
3. 开始前，AI 先看哪些法语内容今天该复习，打算在对话里自然地用到它们。
4. 和 AI 打字对话。纠错是实时的，但和对话分开显示，不打断对话本身；我在对话里用对了到期的词，就算复习过一次。
5. 点击“结束”，AI 生成“本次收获”：对话总结、新词（例句用对话原句）、语法点（链接到变位表等参考资料）、出错的地方。
6. 我在“本次收获”里取消不想要的，确认后存入。已经有记忆卡的词不重复新建，只补充这次的例句；错误记进错误模式；这次练习计入热度图和掌握度。

## 3. 不做什么

- 多人协作：每个人用自己的库，不做多人共享编辑。网页端和手机端暂缓，先专注电脑端。
- 照搬一整套管理方法：GTD 和 OKR 的核心思想融入设计（见第 5 节），其他方法以后做成模板。
- 离开 AI 和网络后基本功能就无法使用的设计。
- 技术方案：留给《总体架构》和《模块说明》。

### D AI 助手

AI 有三种动作，处理方式不同：在对话里说话（讲课、讲解、批评），直接说；按我的指令生成新内容，直接生成；改动我已有的内容，先提议、我确认。AI 不能改任何设置，也不能提议改设置。

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| D1 | AI 不能读密码、私密和机密内容；敏感内容只在我授权的会话里读 | P3 |
| D2 | AI 讲课：按资料讲，每节自我检查，随时调整密度，目标是学得快 | P3 |
| D3 | AI 搜集资料：没有现成资料时先搜、筛选、整理，存进库里再讲 | P3 |
| D4 | AI 批注：对我的文字和笔记的意见，作为批注挂在原文对应位置 | P3 |
| D5 | AI 按指令生成内容：讲稿、小抄（先选用途，如手抄版、一览表）、章节、设定文档 | P3 |
| D6 | AI 定期整理和补全：整理收集箱，补全字段和标签，建议链接，发现重复、过时或该归档的内容；汇总成一批提议，我批量确认。可以在每周复盘或打开软件时运行 | P3 |
| D7 | 对话收尾：自动整理没做完的练习、跳过的内容和悬而未决的问题，放进待补清单；学习类对话结束时先显示“本次收获”，我确认后才存入，已有的记忆卡只补充例句、不重复新建 | P3 |
| D8 | AI 工作约定：全局和每个领域、项目都可以设定 AI 的角色、语气、边界、语言和固定模板（如“只批评不代笔”“一章一对话”），AI 在其中工作时自动遵守；我纠正 AI 时，它提议补进约定 | P3 |
| D9 | 修订编辑界面；权限参考 Claude App，可选“只允许这一次”或“以后都允许” | P3 |
| D10 | AI 读本地代码仓库，帮忙总结学到了什么 | P4 |
| D11 | AI 定期任务：按约定定时执行，比如每周搜一次职缺，结果直接写进库；需要登录的网站使用内置的专用浏览器 | P4 |
| D12 | 和整个库对话：就库里的内容向 AI 提问，比如“我之前关于 OS 调度记过什么”，回答注明出处，遵守隐私层级 | P3 |
| D13 | 常青笔记：AI 发现讲同一件事的笔记，提议合并；一篇塞了太多概念的，提议拆开 | P3 |
| D14 | AI 接入：用户选择自己的 AI 接入方式。内置四种：运行 Claude Code、运行 Codex（都由用户在未修改的程序里自己登录）、Anthropic API key、OpenAI 兼容接口（DeepSeek、Ollama、LM Studio 等，地址和模型由用户填，本地模型可以不填 key）。别的以插件方式加入 | P3；Codex 和兼容接口 2026-11-03 |
| D15 | AI 代为在网页上操作（比如批量投递）：先通过 Claude App 的浏览器扩展（Claude in Chrome）读取软件准备好的材料并填表；以后改用内置的专用浏览器（D11），任何 AI 提供者都能用。每次提交前由我确认，可以一批一起确认；遇到验证码就停下；遵守对方网站的条款 | P3（Claude in Chrome），P4（内置浏览器） |

## 5. 原则与约束

**原则**

- **以本地为主**：没网也能用，不依赖在线服务获取自己的数据。
- **AI 不是唯一通道**：AI 不可用或额度用完时，基本功能照常；能用规则做好的事（提醒、复习排期）不必消耗 AI 额度。
- **AI 的三种动作区别对待**：说话直接说，按指令生成直接生成，改动我的内容先提议（见 D 组）。
- **隐私由软件保证**：AI 能看什么由软件强制过滤，不靠 AI 自觉。
- **数据能带走**：用专有格式，但任何时候都能完整导出。
- **核心简单、零件可组合**：内容类型、视图和学习零件可以不断加进来，不为每个领域单独设计一套功能。
- **默认轻量**：不强制任何整理习惯，字段可选、结构可以后长；维护工作尽量交给 AI，系统本身不能成为负担。
- **GTD 和 OKR 是核心思想**：GTD 的“收集、整理、执行、回顾”循环贯穿日常使用（收集箱、待办状态、每周复盘）；OKR 的“目标、关键结果”把领域、项目和日常行动串起来。两者都是可用的结构，不要求每个项目都套用。此外吸收子弹笔记、间隙日志、常青笔记、决策日记、平衡轮等方法，由 AI 承担其中最费力的记录和整理。

**约束**

- **AI 接入**：每个用户用自己的 AI 账号或密钥。支持 Claude Code 和 Codex（用户在未修改的程序里登录自己的订阅）、Anthropic API key、OpenAI 兼容接口；其他工具和模型以插件方式加入（D14）。不管哪种，AI 只经网关拿受限视图。
- **条款**：软件里不做 Claude 或 ChatGPT 登录，不收集、不保存登录凭据，不代别人付费或转用订阅；不修改 Claude Code 和 Codex，也不禁用或限制它们自带的登录方式；产品名和图标不用它们的名字和标志。Codex 的条款结论见 `docs/spikes/codex.md`。在产品里运行 Claude Code 需要同意 Anthropic 的商业条款，开源发布前确认具体做法。
- **开源、免费**：发布后源代码公开，免费使用。

来源：[Claude Code 法律与合规](https://code.claude.com/docs/en/legal-and-compliance)、[Agent SDK 概览](https://code.claude.com/docs/en/agent-sdk/overview)，2026-10-19 重新查阅。开发时如涉及这两条、开源发布前，都要再查阅最新条款。

## 8. 术语表

完整名词表（界面上和文档里的叫法、容易混的词）见《设计规范》附录 A。

| 术语 | 含义 |
| --- | --- |
| 条目 | 系统里存的任何一样东西的内部名称；界面上直接显示类型名，统称用“内容” |
| 领域 | 长期负责、没有终点的事，比如工作、健康、语言；可以嵌套，如语言 → 法语 |
| 项目 | 有目标、有终点的事，可选，挂在领域下；做完可以归档，归档是一种状态 |
| 学习项目 | 以学会某样东西为目标的项目，可以带截止时间 |
| 收集箱 | 暂时不想分类的新内容先放这里，复盘时再整理（也是一种状态） |
| 待补清单 | 项目里没做完、跳过或悬而未决的事 |
| 学习零件 | 可以组合使用的学习方式，如记忆卡复习、精读注释、对话 |
| 热度图 | 按天显示活跃程度，反映投入了多少 |
| 掌握度 | 根据复习数据算出的实际记住程度 |
| 隐私层级 | 普通（AI 可读）、敏感（AI 可读，但需要我授权）、私密和机密（AI 不可读） |
| 资料库 | 你的全部数据，加密存在本机（文档里也简称“库”） |
| 密码库 | 单独加密存放密码的地方，AI 无法访问（代码和格式里叫 vault） |
| 记忆卡 | 正面、背面的问答，可以选择参与复习 |
| 页签 | 打开的一样内容；分固定、临时、预览三种 |
| 启动器 | 搜索、打开、执行命令、问 AI 的唯一入口 |
| 空间 | 一套布局和打开的页签，可以有多个 |
| MCP | 让 Claude 调用外部工具和数据的协议，软件通过它把内容提供给 Claude |
