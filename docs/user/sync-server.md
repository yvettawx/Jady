# 自建同步服务

`dem-sync-server` 是一个小程序，只存放和转发加密后的文件。它没有密钥，读不到内容。

## 运行

```bash
cargo build --release -p dem-sync-server
```

```bash
DEM_SYNC_TOKEN="$(openssl rand -hex 32)" ./target/release/dem-sync-server --dir /srv/dem-sync --listen 127.0.0.1:8787
```

令牌从环境变量读，不进命令历史和进程列表。把它记下来，每台电脑都要填。

## 一定要加 HTTPS

服务本身不做加密传输。放到公网时，前面要有一个反向代理（如 Caddy、Nginx）处理 HTTPS。软件会拒绝把令牌发到不是 https 的地址，本机地址除外。

内容本身已经加密，HTTPS 保护的是令牌和文件名。

## 连接

设置的“同步”分区选“自己的服务器”，填地址和令牌。令牌只存在系统钥匙串里。

## 服务器能看到什么

文件的路径、大小和时间，也就能大致看出条目数量和活跃程度（见 `docs/format-spec.md` 第 16 节）。看不到标题、正文、字段、标签和类型名。

## 备份

备份 `--dir` 这个文件夹就够了。恢复后，软件会把缺的文件补回去。如果这个文件夹丢了一大半，软件会认为选错了位置或被清空了，这一轮什么都不动，不会把你电脑上的内容也删掉。
