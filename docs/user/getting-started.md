# 开始使用

## 第一次打开

1. **新建资料库**：选位置，设主密码。主密码忘了只能靠恢复码，恢复码要存在安全的地方。
2. **跟着引导走**：选语言、接 AI、选起步模板。每一步都能跳过，之后都能在设置里改。

已经在别的电脑上用了？选“从另一台电脑加入”，见下面的同步。

## 记东西

- `⌘K`：搜内容、运行命令。不知道功能在哪，先按它。
- `⌥⌘N`：在任何地方随手记一笔，内容进收集箱。
- 左边一列是各个视图：今天、目录、搜索、收集箱、待办、学习、生活、AI。
- 内容分四个隐私层级：普通、敏感、私密、机密。层级决定 AI 能不能看到。

## AI

设置的 AI 分区选接入方式，都用你自己的账号：

- **运行 Claude Code**：先在 Claude Code 里登录。软件只负责运行它，不碰你的登录信息。
- **运行 Codex**：先在终端里运行 `codex login` 登录。和 Claude Code 一样，软件只负责运行它。
- **Anthropic API key**：填自己的密钥，只存在系统钥匙串里。
- **OpenAI 兼容接口**：DeepSeek、Ollama、LM Studio 等。填接口地址和模型名，需要的话再填 key。这种方式不能上网。

AI 能看到什么：

| 层级 | AI |
| --- | --- |
| 普通 | 能看 |
| 敏感 | 只在你授权的会话里能看，那时它不能上网 |
| 私密、机密、密码库 | 永远看不到 |

AI 想改已有内容时，会先进“提议”等你决定。不用 AI 也行，其他功能都能用。

## 生活

设置的“模板”里加习惯、书影音、财务、旅行。它们只是几种内容类型，随时能改。

左边“生活”里还有日程、时间轴、关系图、地图、平衡轮和白板。地图不联网，给地点填上纬度和经度就会出现。

## 密码库

密码库有自己的主密码，和资料库分开，没有恢复码，忘了就打不开。5 分钟不用会自动锁定，复制的密码 30 秒后从剪贴板清除。

## 在几台电脑之间同步

文件离开电脑前就已经加密，存放的地方读不到内容，只能看到文件的数量、大小和时间。

**用一个文件夹**：设置的“同步”分区选一个文件夹，比如 iCloud Drive 或 Dropbox 里的。另一台电脑上选“从另一台电脑加入”，选同一个文件夹，再输主密码。

**用自己的服务器**：见 [sync-server.md](sync-server.md)。

离线改的内容下次同步时自动合并。同一个字段两边都改了，较晚的为准，被覆盖的值留在历史里。

## 备份和导出

设置的“资料库”分区能一键导出全部内容，是普通的 Markdown 和 JSON，不依赖这个软件也能读。每种类型一个文件夹，文件名就是标题，图片和文件放在旁边的 `attachments` 里，所以导出的文件夹可以直接当 Obsidian 库打开，`[[链接]]` 都能点。密码库不在其中，它有自己的导出，导出的文件是明文，用完要删。
