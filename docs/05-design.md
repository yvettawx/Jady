## 0. 定位

软件先由我自己用，之后开源、免费推广（PRD v1.2）。软件是一个“半系统”：笔记、学习、求职、财务这些模块像其中的应用，共用一套空间结构、一套命令、一套 AI 入口。设计规范按操作系统设计规范的级别来写：不只描述现在的界面，也规定以后每个新模块、新内容类型、插件怎样长出来。

外壳借用了成熟的工作区形式（Obsidian、VS Code）和 Arc 浏览器的操作逻辑。和 Obsidian 的根本区别不在外壳，而在里面：

| | Obsidian | Jady |
| --- | --- | --- |
| 内容 | 一个个 Markdown 文件 | 带类型和字段的条目（笔记、记忆卡、人物、待办……），能做表格和看板 |
| AI | 插件各自接入，能直接改文件 | 只通过隐私网关；改动一律先变成提议；私密内容在代码层面就看不到 |
| 学习 | 没有 | 复习排期、掌握度、学习零件、做题、AI 讲课 |
| 管理思想 | 靠用户自己约定 | GTD、OKR、回顾写进数据结构 |
| 数据 | 明文文件 | 加密，有版本历史，能完整导出 |

**一句话**：一个本地加密、按类型组织的个人库；AI 在隐私闸门后面帮我学、帮我整理，所有改动先提议。

## 1. 设计原则

1. **一切都是面板**：内容和小组件是同一种东西，同一套规则摆放（已定）。
2. **先看一眼，再决定留不留**：链接先悬浮预览，单击目录先开预览页签，临时页签自动关闭。界面默认不堆积（已定）。
3. **AI 一个入口、三种动作看得出区别**：说话在对话窗口里，生成的结果由你决定放哪，改动一律是提议（已定，对应 PRD D 组）。
4. **隐私看得见**：AI 用不了的地方明确变灰并说明原因，授权对话在页签上标注（已定）。
5. **最左栏管“去哪里”，状态栏管“现在怎么样”**：入口和状态不混放（已定）。
6. **一套命令词汇**：启动器、AI 对话框、正文的 `/` 菜单、命令行工具共用同一套命令（已定）。
7. **键盘能做的都能做，但不用单键**（已定）。
8. **默认安静**：平时只给安静的确认，出问题才醒目；热度图这类少数地方可以放开（建议）。

## 2. 空间结构

### 2.1 窗口骨架（已定）

```
┌────────────────────────────────────────────────────────────┐
│ 标题栏：窗口按钮 · 当前空间 · 少量全局按钮                         │
├──┬─────────────────────────────────────────────────────────┤
│最│                                                         │
│左│   工作区：最多左中右三列 × 每列上中下三格                         │
│栏│   每一格可以叠放多样内容或小组件，用页签切换                       │
│  │                                                         │
├──┴─────────────────────────────────────────────────────────┤
│ 状态栏：当前内容的状态 ……………… 整个软件的状态                       │
└────────────────────────────────────────────────────────────┘
                                          AI 悬浮按钮（四角之一）
```

- **标题栏**自己绘制（建议），macOS 的红绿灯和 Windows 的三个窗口按钮按各自平台的位置放。格式控件不在这里，在编辑页面里（见 6.1）。
- **最左栏**永远在，不能隐藏。
- **AI 悬浮按钮**浮在最上层，只能停在四个角之一，拖动后吸附到最近的角；默认右下角。

### 2.2 工作区与面板（已定）

- 工作区最多分成**左中右三列，每列上中下三格**；列宽、格高都能拖动调整。
- 每一格是一个**面板组**：可以叠放多个面板，用组上方的页签切换（像 Obsidian）。
- **面板**可以是一篇内容（笔记、记忆卡、看板、对话……），也可以是小组件（目录、反向链接、大纲、热度图、待办……）。两者摆放规则完全相同，任何一块都能放，包括中间那列。
- 拖动面板的标题条：
  - 放到某一格的上、中、下区域：吸附到那里，必要时新切出一格（超过三格时提示“这一列最多分三格”）；
  - 放到某一格的页签上：叠放进那一组；
  - 放到空白处：变成悬浮面板，总在最上层，可以收成一条标题；
  - 放进首页：按格子吸附（见 8）。
- 面板变成独立的系统窗口（多屏使用）留到以后。
- 布局改动可以撤销；另有“重置这个空间的布局”。

### 2.3 最左栏（已定）

从上到下：

| 区域 | 内容 |
| --- | --- |
| 左栏视图 | 目录、搜索、收藏、日历的图标，点一下切换左栏导航面板的内容 |
| 通知 | 铃铛，点开是通知列表 |
| 空间 | 每个空间一个彩色方块，点一下切换；“＋”新建空间 |
| 设置 | 齿轮 |

每个图标悬停时显示名称和快捷键。

### 2.4 状态栏（已定）

状态栏只显示状态，不放入口（点开可以看详情）。

| 位置 | 内容 |
| --- | --- |
| 左边，跟着当前内容走 | 保存状态（平时安静地显示“已保存”，失败时醒目）· 隐私层级 · 字数 |
| 右边，跟着整个软件走 | AI（待命 / 正在运行 n 处，点开列出在哪些地方运行）· 同步 · 离线可用 · 当前空间 |

### 2.5 空间（已定）

- 参考 Arc。一个空间有自己的布局、打开的页签、首页和颜色。
- 用不用由自己决定，默认只有一个“主空间”。
- 可以选择绑定一个领域（绑定后左栏目录只显示这个领域），不强制。
- 切换：点最左栏的方块；快捷键见 11；Mac 触控板两指左右滑动。

### 2.6 窗口变窄时（已定）

先收右侧的列，再收左侧的列；最左栏永远在。收起的列在边缘留一条可以点开的窄边。

## 3. 打开与导航

### 3.1 打开方式（已定）

| 操作 | 结果 |
| --- | --- |
| 目录里单击 | 预览页签：标题显示成斜体，下一次单击会替换它 |
| 目录里双击，或在预览页签里开始编辑 | 变成正式的临时页签 |
| 正文里点链接 | 悬浮预览 |
| ⌘+点击链接（Windows：Ctrl+点击） | 直接在新页签打开 |
| ⇧+点击链接 | 直接在旁边分屏打开 |
| 表格、看板里点一行 | 详情从右边滑出，盖在表格上 |
| 详情里再点链接 | 弹出一个更小的悬浮预览 |
| 再次打开已经开着的内容 | 开一个新页签；两个页签都能编辑，改动实时同步 |

### 3.2 页签（已定）

- **三种状态**：预览（斜体，会被替换）、临时（默认）、固定（◆，不会自动关闭）。
- **自动关闭**：临时页签 24 小时不碰就自动关闭，时间可以在设置里改；在“最近关闭”里能找回。
- **排法**：默认用“打开的内容”小组件竖排列出所有页签（固定的在上，临时的按时间排在下），放在左栏上半；每个面板组上方只留一条细标题。设置里可以切换成每组上方横排页签。页签栏上不放切换按钮，只在外观设置里改（2026-10-21）。
- **换位**：横排时，页签可以在页签栏里拖动换位，也可以拖到另一组的页签栏里叠放。竖排的“打开的内容”列表里也能拖动换位：拖过以后按你排的顺序，不再按时间重排，新开的临时页签排在临时区最上面；固定和临时两区之间不能拖过界，要固定就用“固定”（2026-10-21）。
- **授权对话**：授权对话和联网授权对话的页签上有标注，两种标注不同。

### 3.3 悬浮预览（已定）

- 就是一个方便关掉的小窗口，内容可以直接编辑。
- 关闭：Esc，或点小窗口外面。
- 展开成页签：⌘+回车，或点“打开为页签”；分屏：⇧+回车，或点“分屏”。
- 预览里再点链接，在同一个小窗口里前进，可以后退。

### 3.4 分屏

分屏就是把面板放进工作区的不同格，规则同 2.2，最多左中右 × 上中下。

### 3.5 查看方式（已定）

- 每个页签有自己的查看方式：**编辑**（所见即所得，默认）或**阅读**（只看不改）。
- 代码块、Mermaid 图、SVG 这类内容在块内左边写源码、右边看效果。
- 不做整页 Markdown 源码模式；Markdown 的导入导出由格式转换器负责。

### 3.6 拖放的含义（已定，沿用 M11）

| 拖到哪里 | 含义 |
| --- | --- |
| 正文里 | 插入链接 |
| 工作区的某一格 | 在那里打开 |
| 页签栏里 | 调整页签顺序，或叠放到那一组 |
| 目录树里 | 移动到另一个领域或项目 |
| 看板的另一栏 | 改状态 |
| 正文内部 | 调整段落顺序 |

### 3.7 键盘和焦点（2026-11-02）

- 所有事都能只用键盘做完。Tab 按看到的顺序走，方向键在一组里面走（列表、树、页签、菜单）。焦点的样子只在用键盘时出现。
- 打开什么，焦点就到哪里：对话框到第一个安全的按钮（有确认的是取消，回车不会误确认），启动器和对话窗口到输入框，详情到标题。
- 关掉什么，焦点就回到打开它的地方。
- 按下的东西自己消失时（确认后的按钮、关掉的窗口），焦点去最近还在的卡片或这一页，不能掉出页面（`src/ui/focus.ts` 统一兜底，新界面把卡片和页面标成落脚点）。
- 后台的页签不抢焦点。
- Esc 从最上面一层关起，一次一层：提示框、菜单、预览、对话框、详情。输入框里有字时 Esc 不关窗口。提示框随它的按钮一起消失，不留在屏幕上吃掉下一次 Esc。
- 输入法组字时，回车和 Esc 归输入法。
- 单个字母和数字的快捷键只在没有输入框有焦点时算数（比如复习页的 1、2、3）。

### 3.8 拖放反馈（2026-11-02，含义见 3.6）

- 拖动中：原来的东西变淡留在原位，拿在手上的是一个小影子，写着标题。
- 能放的地方亮起：页签之间是一条细线，一格的四边是盖住那部分的半透明区域，看板的一栏整栏亮。不能放的地方不亮，也不弹解释。
- 松手时东西移动到位，有过渡；减少动效时直接到位。
- Esc 取消拖动，东西回到原位。
- 键盘也能拖：回车拿起，Tab 或方向键选位置，回车放下，Esc 取消。
- 放下之后能撤销（3.9）。

### 3.9 确认和撤销（2026-11-02）

- 能撤销的直接做，给撤销提示。移到回收站、改状态、批量修改、移动都是这样。
- 撤销不了的才先确认：清空回收站、调低隐私层级、放弃本次收获。确认框写明会发生什么，按钮写动作（“删除”“改成普通”），焦点在取消上。
- AI 的删除提议永远要确认（5.4）。
- 撤销提示留 8 秒，指针停在上面或焦点在上面时不消失；普通提示留 5 秒。一次操作只有一条提示。过了提示还能从 ⌘Z 或操作记录撤销，具体由 P1 的数据层定。回收站保留多久也由 P1 定。

## 4. 启动器与指令（已定）

### 4.1 入口

只有一个启动器、一个快捷键（建议 ⌘K / Ctrl+K，待实测）。点 AI 悬浮按钮也打开它。对应 PRD H2。

### 4.2 指令

| 开头 | 做什么 | 例子 |
| --- | --- | --- |
| 直接输入 | 搜索内容和命令，内容排前面；支持拼音首字母 | `法语`、`fy` |
| `>` | 只找命令 | `>新建记忆卡`、`>切换空间 学习` |
| `?` | 问 AI，回车后变成一个对话小窗口 | `?这周法语学了什么` |
| `?/` | AI 快捷指令 | `?/总结`、`?/整理`、`?/出题 5`、`?/讲解` |
| `+` | 快速新建，默认放进收集箱 | `+买火车票`、`+记忆卡 le quai 站台`、`+待办 周一问实习 A` |
| `#` | 按标签找 | `#求职` |
| `@` | 限定范围（领域、项目或空间），可以和其他符号组合 | `@法语 ?总结这周的错误` |

- 全角、半角符号都认，不用切输入法。
- 在某个页签里问 AI，对话自动关联这个页签；用 `@` 可以改范围。

### 4.3 按键

| 按键 | 效果 |
| --- | --- |
| ↑ ↓ | 选择 |
| 回车 | 执行，或打开选中的结果 |
| ⌘+回车 | 在新页签打开 |
| ⇧+回车 | 分屏打开 |
| Tab | 补全命令名 |
| Esc | 关闭 |

### 4.4 一套命令词汇

启动器、AI 对话框、正文的 `/` 菜单、P2 的命令行工具都用同一套命令名和写法，由 M11 的命令登记机制统一管理。新模块、插件加命令也走这里。完整的命令清单放在本文档的附录（后续补）。

## 5. AI 交互

### 5.1 三种动作在界面上怎么区分（已定，对应 PRD D 组）

| 动作 | 在哪里 | 怎么生效 |
| --- | --- | --- |
| 说话（讲解、回答、批评） | AI 对话窗口里 | 直接显示 |
| 按指令生成新内容（总结、讲稿、记忆卡） | 先出现在对话窗口里 | 由你点“插入原文下方”或“存为新笔记” |
| 改动已有内容（整理、补全、合并） | 变成提议 | 你确认后才生效，可以撤销 |

### 5.2 入口（已定）

- 启动器里输入 `?`。
- AI 悬浮按钮（打开启动器）。
- 正文选中内容后右键“问 AI”：打开一个和当前页签关联的 AI 对话悬浮窗，选中的内容作为上下文；总结、整理等都在这个对话里继续。

### 5.3 AI 对话窗口（已定）

- 默认是悬浮的小窗口，也能像面板一样吸附进工作区。
- 可以同时开多个对话，互不阻塞，也不锁住其他操作。
- 每个对话自动和发起时的页签关联，关掉后存成一条记录；启动器和左栏都能找回。
- 在学习零件这类内容里（比如法语实时对话），AI 就是页面本身，不另开窗口；纠错和对话分开显示。

### 5.4 提议（已定）

- **同一条提议出现在三处**：左栏的“AI 提议”、原文对应段落右边的一个小点、AI 对话窗口里。在任何一处确认或忽略，三处同时更新。
- 确认时可以选“只这一次”或“以后这类都允许”（PRD D9）。
- 所有生效的提议都能撤销（PRD F4）。
- “这类”是同一种动作加同一个范围（如“补全标签，在法语领域内”）。规则只能由你按按钮产生，列在设置的 AI 分区，随时可以撤回，AI 不能改（2026-11-02）。
- 删除没有“以后都允许”，也不进“全部确认”；敏感内容上的提议不能设规则；原文已经改过的提议只能忽略（2026-11-02）。

### 5.5 运行状态（已定）

- 状态栏显示“AI 正在运行 n 处”，点开列出在哪些地方运行，点一项跳过去。
- AI 按钮在有提议或正在运行时变亮，空闲时变淡（建议）。

### 5.6 隐私在界面上的表现（已定）

- 私密、机密内容里：右键的 AI 项变灰，并写明“私密内容，AI 看不到”；启动器里 `?` 针对这类内容时同样提示。
- 敏感内容：只在授权对话里能用 AI。授权对话里上网关闭；联网授权对话里上网开着，但只能用你逐条标了“可以联网给 AI 用”的条目。标记在条目的隐私设置里，由你本人确认，随时可以撤回，AI 不能改。
- 右键“互联网搜索”：私密、机密内容时变灰；敏感内容先确认再搜。
- “可以联网给 AI 用”在笔记的隐私层级菜单里，只对敏感内容出现；打开要确认，撤回立刻生效。标过的内容开 AI 时，可以选授权对话或联网授权对话（2026-11-02）。

### 5.7 AI 调用命令（已定，2026-10-19）

- 启动器里的命令也开放给 AI，通过网关工具调用，比如“打开投递看板，按截止日期排，只看还没回复的”。
- 只改界面的命令（打开、筛选、排序、切换空间）：直接执行。
- 会改数据的命令：照样变成提议（5.4）。
- 改设置的命令（外观、快捷键、AI 接入、隐私、授权等）不开放给 AI，连提议都不行；AI 最多在对话里告诉你设置在哪。

### 5.8 AI 接入（已定，对应 PRD D14）

- 每个用户用自己的 AI 账号或密钥，在设置里选择接入方式：运行 Claude Code、运行 Codex（都由用户自己登录）、Anthropic API key 或 OpenAI 兼容接口（填地址和模型，key 可选）；插件可以加入别的提供者。接入方式多于三种，所以用下拉框，不用分段按钮。
- 选 Claude Code 时，软件只检测它是否安装、是否已登录；没登录就提示用户去 Claude Code 里登录。软件里没有任何 Claude 登录框，也不碰登录凭据。
- 状态栏的 AI 一项显示当前用的是哪种接入；AI 不可用时，基本功能照常（PRD 第 5 节）。

## 8. 首页（已定）

- 打开软件先看到首页。每个空间一个首页。
- 首页背后是三维星图，前面是小组件（2026-10-21）。首页时左栏、右栏、页签栏都不显示，只留最左栏；点最左栏的图标，目录等面板会浮出来，点空白处收起。
- 星图：条目按链接聚成星团，每团标名字和条数；悬停时相连的条目亮起，点一下打开。星图只在首页渲染，离开首页就停。外观里可以关掉。
- 首页本身也是一个面板；里面的小组件按格子吸附，可以拖动、调整大小、增删（PRD H4）。
- 进出首页（2026-10-25）：首页是每个空间固定的第一个页签，它在前台时就是首页的样子。再点一次最左栏当前空间的方块，或按 ⌘⇧H（Windows：Ctrl+Shift+H），回到首页；从浮出的面板或启动器打开内容，回到工作区原来的样子。
- 首页上的小组件和工作区里的是同一种东西：热度图可以从首页拖进侧栏，反之亦然。

### 8.1 热度图（2026-11-02 选定年历墙）

- **样子**：周为列、天为行（周一在上），Canvas 自绘。方块的颜色是当天最多的类型，第二多的占到两成以上时，底部按比例露出它的颜色，最多两色，其余看卡片。方块亮度按当天总量，第 95 百分位算满，开平方，这样一天特别忙也不会压暗其他日子。没有活动的日子是一个淡格子。
- **颜色**：全部读 `content-*` 令牌，用户改了颜色或换深浅色都跟着变。类型是开放的：以后的提交记录、习惯打卡只是新的类型，绘制代码不变。
- **动效**：打开时从左到右扫进来，每格带一点回弹；指针周围的方块微微涨大；最忙的日子有一圈溢光（小尺寸不画）。系统减少动效时这些都不播，直接画好。没有变化时不重绘。
- **大的**（铺满一格）：显示整年、月份、连续天数、这一年的总数和类型图例，点图例筛掉一种类型。点一天浮出卡片：各类型的数量和当天改过的内容，点标题打开。
- **小的**（首页小组件）：显示最近几周，方块最大 13 像素，放得下多少周算多少，只留连续天数。点一天在工作区打开大的，并停在这一天。
- **键盘和读屏**：方向键左右换一天、上下换一周，回车等于点这一天，Esc 退出；每换一天读出日期和次数。
- **隐私**：机密内容计入数量，标题不出现在卡片里；私密内容的标题可以出现，带锁。给 AI 用的统计完全不算私密和机密内容，由 P1 的受限视图保证。

## 9. 通知与提醒（已定）

- 铃铛在最左栏，点开是通知列表。
- 系统通知只在有事时出现（PRD E3）。
- 状态栏不显示通知数量，避免重复。
- 通知只说有事要你做或做好了的事，写具体的数量和名字（“6 张记忆卡该复习”）。AI 跑完一批提议算一条，不一条条弹（2026-11-02）。
- 敏感、私密内容的通知不写内容，只写类型和数量；机密内容不发通知（2026-11-02）。

### 9.1 空状态（2026-11-02）

- 写这里没有什么，再给一个能做的动作，就这两样。不鼓励、不解释这个功能是什么。比如“没有等你决定的提议”“今天没有待办”。
- 两种情况要分开：本来就空（给新建）；搜索或筛选后没有结果（说没找到，给清除条件）。
- 小组件和侧栏里只写一句，不放插图。

## 11. 快捷键

### 11.1 原则（已定）

- 不用单键；每个快捷键都带修饰键。
- 系统惯例（复制、粘贴、撤销、查找等）不改。
- macOS 的 ⌘ 对应 Windows 的 Ctrl，⌥ 对应 Alt。
- 同类操作用同一族组合。
- 避开系统和中文输入法占用的组合（比如 Ctrl+空格、⌘空格）。
- 全部可以在设置里改，改的时候检查冲突（PRD H2）。

## 12. 新手引导（建议，对应 PRD H8，P5 做完整版）

第一次打开软件时，依次：

1. **建库**：设主密码，显示并要求保存恢复码。
2. **选语言**。
3. **设置 AI 接入**：检测本机有没有 Claude Code、是否已登录；没有就给安装指引，或者改填 API key；也可以先跳过，以后在设置里开。

## 13. 多语言（已定结构，对应 PRD H7）

- 所有界面文字放语言资源文件，不写死在代码里；P1 起就这样做。
- 先做中文，开源发布时加英文。
- 日期、数字、单位按当前语言显示；历史日期（公元前、约某年）的说法也随语言变。
- 命令名多语言：中文命令同时能用拼音首字母和英文名搜到。
- 启动器的指令符号（`> ? + # @`）和语言无关。
- 快捷键的显示按平台（macOS 显示 ⌘，Windows 显示 Ctrl）。

## 14. 文案规范（已定，2026-10-20）

界面文字、软件里 AI 生成的内容、文档和提交说明都照这一节写。目标是具体、直接；去掉下面这些也不等于写得好。

**该删的**

1. 用户看得见的东西不解释。状态用安静的标记（锁的图标、“私密”），原因只在悬停或真的被拦住时给。
2. 不用“XX · XX”点连格式。层级靠排布表现（目录、带图标或斜杠的路径）。
3. 按钮只写动作，两三个字：结束、存入、确认。
4. 不写开场白、客套话和收尾的总结。

**不用的句式**

5. 不用“不是 X，而是 Y”“不仅 X，还 Y”。
6. 列举不凑数，有几个写几个。
7. 不用长破折号，也不用冒号后抖包袱的写法。
8. 不用空泛大词：赋能、打造、助力、无缝、全方位、深度、极致、闭环、抓手、值得注意的是、总的来说、不难发现。

**格式**

9. 少加粗；不用表情和装饰符号当标记。
10. 一句话能说完，就不拆成列表；标题不写成“关键词：解释”。

**怎么写**

11. 写具体的数量和名字，比如“6 张记忆卡该复习”。涉及隐私的地方（锁屏通知、敏感和私密内容）不写具体内容。
12. 主语明确，用主动句，比如“已确认”。不用“进行了确认”这类翻译腔。
13. 语气平实：不热情、不卖萌，系统不自称“我们”。

**中文排版（2026-11-02）**

14. 中文和英文、数字之间加空格：“第 12 课”“AI 提议”“6 张”。百分号、度数和紧跟数字的单位符号前不加：“100%”。
15. 中文里用全角标点，英文和代码里用半角。外文句子保留它自己的标点（法语问号前的空格等）。
16. 外文内容标上语言（`lang`），字形和读屏才对。
17. 这些规则管界面文字和 AI 生成的内容；你自己写的笔记不自动改。

能机器判断的几条由 `src/i18n/copy.test.ts` 钉在文字表上。

这套规则同时是默认的全局 AI 工作约定（PRD D8），用户可以改。

## 15. 视觉方向（已定，2026-10-21）

令牌和组件外观在 P0.5-04、P0.5-06 细化，这里先定方向。

- **液态玻璃**：外壳（最左栏、侧栏、悬浮层、小组件）是半透明玻璃，透出空间颜色的壁纸；正文是一张实底的纸。侧栏、最左栏、正文区是悬浮的圆角玻璃片，四周留空。玻璃有一圈亮边和跟着指针的高光，背后内容轻微折射，按下时轻微缩小。
- **外观设置**：配色方案（默认极光）、空间颜色、壁纸、液态玻璃（透明或着色，加透明度滑块）、页签排法、长文字体、减少透明度、首页场景（星图或不显示）。
- **形状和动效**：小圆角；动效有弹性；关键时刻从点击的位置展开。
- **点缀**：少量霓虹的光；首页时钟、档案编号等大字带溢光；数字滚动出现。
- **编号和小标签**：小组件标题前有编号，右边有英文小标签；笔记开头显示档案编号。英文小标签也算界面文字，同样放进语言资源文件。
- **减少动效、减少透明度**：系统的减少动效偏好打开时，滚动数字、溢光动画、星图动画都停；减少透明度时玻璃变成实底，首页场景可以关掉。

### B.2 液态玻璃

- 玻璃的颜色：浅色是白，深色是 #12121c。滑块范围 0.1–0.85，默认 0.3。
- 实际涂上去的不透明度：“透明”档 = 底数 + 滑块 × 0.5（底数浅色 0.18、深色 0.28），所以最透的一档也不会完全透明；“着色”档 = 滑块 + 0.12，再混进 20%（深色 18%）的空间颜色。这个换算写在 `glassAlpha()`，运行时也调用它。
- 亮边四档、高光、亮度系数、溢光都是令牌：`glass-rim-1…4`、`glass-spec`、`glass-bright`、`glow`；模糊半径 `glass-blur` 由滑块决定。
- 亮边的最亮处和高光都跟着指针走；一个窗口只有一个指针监听，每帧最多更新一次（2026-10-21）。
- 壁纸和首页场景上的玻璃由 WebGL 背景层画模糊、折射和颜色，DOM 面板只负责内容、亮边和高光；盖在正文上的弹出层用接近不透明的纸加 CSS 模糊，因为背后的文字画不进背景层（2026-10-21）。
- “减少透明度”打开时，玻璃变成实底的纸，背景层不画折射。软件里的开关和系统的设置（macOS 辅助功能里的“减少透明度”、Windows 关掉“透明效果”）任一打开都算；系统打开时，软件里的开关显示为打开且不能关，旁边注明“系统设置里已打开”。系统设置在窗口重新获得焦点时重新读取（2026-10-22）。
- WebGL 折射只给固定在窗口上的玻璃用（外壳、小组件、停靠分组），背后只能是壁纸或首页场景。会随内容滚动的玻璃，或者内容会从底下经过的玻璃，改用 CSS 模糊：背景层画不出内容，而且滚动时它会比页面慢一帧，出现错位的影子。所以外壳不滚动，滚动只发生在面板内部（2026-10-21）。
- 首页时，玻璃由星图在它自己的 WebGL 里画，作为最后一步；背景层只把各块玻璃的位置交给它。每帧把星图画面复制给背景层在 WKWebView 里太慢（见 `docs/spikes/07-ui-components.md` 的 P0.5-07-3 一节，2026-10-26）。从最左栏浮出的面板盖在首页的文字和小组件上，按上一条用 CSS 模糊。

### B.3 字体（已定，2026-10-21）

字体分四个位置，每个都能在“外观”里单独换：

| 位置 | 令牌 | 默认 |
| --- | --- | --- |
| 界面 | `font-ui` | 系统字体：苹方、微软雅黑 |
| 长文 | `font-long` | 霞鹜文楷；没有时退到思源宋体、系统宋体 |
| 等宽 | `font-mono` | JetBrains Mono |
| 标题与编号 | `font-display` | Archivo（宽体，用于编号、时钟、英文小标签） |

另有 `font-rare`：西夏文等罕见文字的字体，用到时再下载，接在每条字体链的末尾。

每个位置可以选的字体有三种来源：

1. **系统里装好的字体**：列出这台电脑上所有字体，直接选。
2. **推荐字体**：霞鹜文楷、霞鹜文楷屏幕阅读版、思源宋体、思源黑体等开源字体。点一下从官方发布页下载原版文件，存到本机的应用数据目录，并显示它的许可。
3. **导入自己的字体文件**：.ttf、.otf、.woff2，同样存到应用数据目录。

规则：

- 字体文件不放进资料库，不随内容同步；设置里只记字体名。换到没有这个字体的电脑上，就按字体链往下退。
- 主题包可以带字体，但字体本身的许可必须允许再分发。
- 联网下载只在你点了以后发生。
- 霞鹜文楷用的是 SIL OFL 1.1 许可，带保留字体名：原版文件可以随软件分发，改过（比如裁剪、转换格式）就不能再叫“霞鹜”。所以只用原版文件，不做裁剪。一个字重约 26 MB。

已定：霞鹜文楷 Regular **随软件分发**，装好就能用，没网也行，安装包大约多 26 MB。粗体用的 Medium 字重（同样约 26 MB）在第一次用到时再下载。

建议的做法：字体文件不提交进 Git 仓库；构建时从官方发布页下载固定版本，用 SHA-256 校验后打进安装包，许可文件一并带上。P0.5-06 加载字体时实现。
