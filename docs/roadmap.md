# 路线图

P0 到 P4 的功能都有了，P5 里不需要外部账号和决定的部分也做了。下面是还没做的，按我建议的顺序。

## 发布前必须做

这些需要你：

1. **自己用一段时间**。P1 的完成标准写着持续用两周，所有功能都还没经过真实内容的长期检验。
2. **图标、查名字、应用标识、贡献者协议**，见 `docs/release/checklist.md`。许可证已定 AGPL-3.0，名字已定 Jady。
3. **Apple 开发者账号**，用来签名和公证，发布时再办。没有的话别人下载后会被系统拦住。
4. **定发布地址和更新签名密钥**，然后才能接自动更新。
5. **确认在产品里运行 Claude Code 和 Codex 的条款**，开源发布前重新查一次。Codex 这次没找到 OpenAI 的明确说法，见 `docs/spikes/codex.md`。
6. **装上 Codex 实测一遍**：`PROBE_PROVIDER=codex node probe/real-ai.mjs`。现在的收紧是按文档和源码做的。

## 发布后优先做

- **外部插件能用的界面能力**：现在只能加面板和命令（`docs/extending/external-plugins.md`）。首页小组件、侧栏视图、配色等有人要时再加。
- **同步的存放后端**：现在有文件夹和自建服务，S3 和 WebDAV 可以加。扫码加入新电脑也还没做，现在输主密码。
- **批注的稳定位置和正文高亮**、时间块和待办的双向完成。
- **工作流编辑器**：拖节点连线，把定期任务升级成节点图，思路来自 Dify，见 `docs/spikes/dify.md` 第 7 条。先等你试用一段时间，想清楚最想自动化哪几件事，再按真实例子定节点，不先堆一大堆。

## 暂缓，什么时候重新考虑

| 事项 | 什么时候再看 |
| --- | --- |
| Windows、Linux | macOS 版本稳定、有人要的时候。代码没有故意写死平台，但没有为它们测试 |
| 手机端 | 同步用稳定之后。格式已经支持多设备；手机上最先做收集和复习 |
| 网页端 | 手机端之后。要解决浏览器里的密钥保管，不着急 |
| 向量搜索、语音收集、Share Extension | 有明确需要时 |
| 兼容接口的上网 | 要在网关里做一个过滤本机和内网地址的读网页工具，和 Claude Code 的读网页一起换 |
